# Setup — __AGENT_NAME__

This agent was generated by agent-factory. Its name, port (`__AGENT_PORT__`),
and cron schedule (`__CRON_SCHEDULE__`) are already set. What remains is:
provide secrets, onboard it in a conversation, then launch it as a persistent
container.

Plan for ~1 hour end to end — most of that is Docker installing things.

## Prerequisites

- **Docker** — installed and running.
- **agentbox** — the interactive Claude Code container used for onboarding.
  Clone and install from <https://github.com/robhunter/agentbox> (needs Bash 4+;
  on macOS `brew install bash`).
- **agent-portal** — the framework. Clone it as a **sibling directory** of this
  agent (`docker-create.sh` resolves it as `../agent-portal`):
  ```bash
  git clone https://github.com/robhunter/agent-portal.git
  ```
- A **Claude.ai** account to OAuth with, and a **GitHub token** with `repo`
  scope (so the agent can commit and push its pushed tier).

## 1. Create your `.env`

`.env` is gitignored — it stays on your machine:

```bash
cat > .env <<'EOF'
GH_TOKEN=ghp_your_github_token_here
GIT_AUTHOR_NAME=Your Name
GIT_AUTHOR_EMAIL=you@example.com
EOF
```

## 2. Onboard (interactive)

From this directory, start an interactive session:

```bash
agentbox
```

The agent detects it is uninitialized and runs the onboarding conversation
(~15-25 min). At the end it writes your answers into `memory/*.yaml`, sets an
initial `data/today.md`, and commits. Exit with Ctrl-D when it tells you to.

## 3. Launch (persistent)

Create the long-running container and install the framework inside it:

```bash
bash ../agent-portal/scripts/docker-create.sh .
```

Then authenticate Claude inside the container:

```bash
docker exec -it __AGENT_NAME__ bash -c 'source ~/.nvm/nvm.sh && claude'
```

Install the cron wake cycle:

```bash
bash ../agent-portal/scripts/cron-setup.sh . install
```

The agent now wakes on its schedule. The web portal is served on port
`__AGENT_PORT__`.

## State & recovery

- The **pushed tier** (`memory/`, code) is on your GitHub remote — clone it to
  recover identity and operating knowledge anywhere.
- The **local-only tier** lives in `data/.git` on the container/host and is
  never pushed. To roll back a bad day: `git -C data log` to find a good
  snapshot, then `git -C data reset --hard <commit>`.
