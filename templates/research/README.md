# __AGENT_NAME__

A persistent autonomous research agent, generated by
[agent-factory](https://github.com/robhunter/agent-factory) from the `research`
template. Similar in shape to Bobbo: it wakes on a schedule, reads its memory,
does research/work for its human, journals what it did, and notifies sparingly.

Runs in Docker on the [agent-portal](https://github.com/robhunter/agent-portal)
framework, with an interactive [agentbox](https://github.com/robhunter/agentbox)
session for onboarding and calibration.

## First run

This agent starts **uninitialized**. The first time you launch it interactively
(`agentbox` in this directory), it detects the `status: uninitialized` sentinel
in `memory/persona.yaml` and runs a 15-25 minute onboarding conversation to
learn who you are and what you want. See [ONBOARDING.md](./ONBOARDING.md) and
[SETUP.md](./SETUP.md).

## Two-tier state

- **Pushed** (`memory/`, `skills/`, code): identity + durable operating
  knowledge (`memory/operational.yaml`). Committed and pushed to the remote.
- **Local-only** (`data/`): journals, logs, outputs, `today.md`. Committed to a
  private git repo inside `data/` that is **never pushed** — snapshotted each
  cycle so you can reset to a prior day if something goes wrong. Human feedback
  under `data/input/` is not committed at all.
